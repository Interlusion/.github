# Interlusion

**Fantastic apps. Built by agents. Designed by humans.**

Interlusion is an AI-native technology company from Dortmund. It builds digital products and intelligent systems with an agent-assisted workflow. Kersten Lorenz designs the architecture, directs the agents and reviews every change. The agents do the heavy lifting.

## What Interlusion builds

- **Development.** Software architecture, agent-assisted development and MVPs, from concept to production.
- **AI services.** RAG and knowledge systems, private AI on open-weight models, custom agent systems.
- **Design.** UI/UX, design systems and data visualisation, planned alongside the architecture.
- **Research.** Applied AI research that ships, not research that publishes.

## Open source

- **[Erpel](https://github.com/Interlusion/erpel):** ERPNext MCP done right.

## The team

More than 50 agent personas in 13 departments. Darbit, a time-travelling rabbit-robot, runs them as Chief AI Officer. Prof. Dr. Gutensieben leads research. One human sets the direction. Meet them on the [team page](https://interlusion.dev/en/team/).

## Built by Interlusion

- **[Bettles](https://bettl.es):** built solo, from UI to backend to infrastructure, and rewritten from scratch in about six months. Live since June 2026.
- **Interlusion Platform:** a highly available Kubernetes cluster on Hetzner Cloud, run by one person with GitOps and AI-assisted operations.
